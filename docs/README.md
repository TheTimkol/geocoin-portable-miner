# GeoCoin · Пошаговый запуск

Неофициальная русскоязычная страница-помощник для Windows 10/11: кошелёк GeoCoin, отдельная нода, синхронизация и подключение [GeoCoin Portable Miner](https://github.com/TheTimkol/geocoin-portable-miner) с CPU/OpenCL GPU.

## Запуск

Откройте `index.html` в браузере. Установка библиотек или локального сервера не требуется. Отметки чек-листа сохраняются только в локальном хранилище браузера.

Это неофициальный гид сообщества; он не означает, что автор оригинала одобрил или выпустил эту страницу. Перед запуском сверяйтесь с актуальными материалами GeoCoin и portable-майнера. Для сборки portable-майнера нужны JDK 21+ и Maven 3.9+; его первый запуск требует редактирования `config.properties` и файла `rpc-miner.pass`.
