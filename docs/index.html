01

Возьмите официальную сборку

Перед запуском

Проверьте страницу релизов GeoCoin. Если пользовательского архива пока нет, сборка описана в официальном руководстве.

Важно: скачивайте ноду и кошелёк из официального GeoCoin. Проверяйте страницу Releases: если готовой сборки нет, в руководстве есть команды сборки. Этот маршрут рассчитан на Windows 10/11 x64 и ваш portable-майнер.
Открыть релизы Руководство по сборке ↗
✓Не распаковывайте новую версию поверх папки с данными кошелька или ноды.
02

Подготовьте кошелёк и адрес награды

Один раз

Откройте GeoCoin Core, создайте кошелёк и скопируйте адрес, который укажете майнеру.

В обычном режиме geocoin-core запускает собственную локальную ноду. Сохраните доступ к кошельку и резервную копию по официальной инструкции. Когда будете переходить к отдельной ноде для RPC-майнинга, закройте окно кошелька.
Запуск кошелькаWindows · portable
.\bin\geocoin-core.exe
✓Скопируйте адрес для получения награды. Сделайте резервную копию кошелька и храните её отдельно вместе с паролем. Не отправляйте кому-либо пароль или файлы кошелька.
03

Запустите ноду с доступом для майнера

Только localhost

Для внешнего CPU/GPU-майнера ноде нужны включённый RPC и отдельные учётные данные майнера.

Не открывайте RPC в интернет. Оставьте привязку к 127.0.0.1. Создайте два пароля: отдельный для администратора и второй для майнера. Запомните пароль miner: тот же пароль понадобится portable-майнеру.
Показать, как создать файлы паролей
Windows · PowerShell
$rng = [Security.Cryptography.RandomNumberGenerator]::Create()
$adminBytes = New-Object byte[] 32
$minerBytes = New-Object byte[] 32
$rng.GetBytes($adminBytes)
$rng.GetBytes($minerBytes)
$admin = [Convert]::ToBase64String($adminBytes)
$miner = [Convert]::ToBase64String($minerBytes)
Set-Content -NoNewline .\rpc-admin.pass $admin
Set-Content -NoNewline .\rpc-miner.pass $miner

iСоздайте файлы в папке ноды. Позже сохраните тот же пароль miner в rpc-miner.pass рядом с portable-майнером. Не публикуйте эти файлы.

Команда запуска нодыWindows · основная сеть
.\geocoin-node.cmd --data-dir .\data --network degree --rpc --rpc-bind 127.0.0.1 --rpc-user admin --rpc-pass-file .\rpc-admin.pass --rpc-miner-user miner --rpc-miner-pass-file .\rpc-miner.pass
✓Параметр --network degree запускает основную сеть. Для тестовой сети используйте отдельную папку данных и её manifest из официального репозитория.
04

Дождитесь полной синхронизации

Зависит от сети

Пока нода догоняет сеть, майнер ещё рано запускать. Оставьте окно ноды открытым.

1В логах ноды появляются подключения к пирам и новые блоки.
2Высота локальной цепочки перестала отставать и продолжает обновляться.
3Для диагностики используйте RPC-метод getmininginfo и официальную справку.
Порядок: окно ноды должно работать всё время, пока запущен майнер. Если останавливаете компьютер, сначала завершите майнер.
05

Настройте и запустите GeoCoin Portable Miner

Старт только после подтверждения

Подключите ваш переносной CPU/OpenCL-майнер к локальной ноде. Он не начинает майнинг, пока вы не введёте команду start и не подтвердите адрес.

Открыть мой майнер на GitHub ↗ Как собрать программу ↗
1Для сборки нужны JDK 21+ и Maven 3.9+. В папке проекта запустите scripts\build.cmd, затем run.cmd. Если готовый комплект опубликован в Releases, используйте его.
Параметры файла config.properties
node.url=http://127.0.0.1:3033/
node.username=miner
mining.address=ВАШ_GEOCOIN_АДРЕС
mining.threads=1
limits.cpu-percent=35
gpu.enabled=false
gpu.devices=
2Скопируйте config.example.properties в config.properties. Укажите адрес награды и имя miner. Создайте рядом файл rpc-miner.pass с тем же паролем miner, что задан ноде. Если файла нет, программа создаст пустой и попросит заполнить его.
Запуск и управление
.\run.cmd
start
status
stop
3После start подтвердите свой адрес, введя YES. Команда status покажет скорость, stop завершит майнинг.
Майнинг использует процессор и может повышать нагрев и расход энергии. Начните с 1 потока и небольшого лимита CPU. Доход не гарантирован.
У меня видеокарта

iВаш майнер использует OpenCL (видеокарты NVIDIA, AMD и Intel с подходящим драйвером). Запустите программу с gpu.enabled=false, введите gpu devices, впишите найденные ID в gpu.devices, включите gpu.enabled=true и перезапустите программу. При необходимости задайте умеренный limits.gpu-percent.

Готово. Ваша нода и майнер работают отдельно

Для остановки сначала завершите CPU/GPU-майнер, затем корректно остановите ноду. Состояние чек-листа можно сбросить внизу страницы.
